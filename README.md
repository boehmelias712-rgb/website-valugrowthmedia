# ValuGrowthMedia Website

Eine moderne, responsive Website für ValuGrowthMedia mit animations-gestütztem Design.

## Features

- 🎨 Modernes Dark-Mode Design mit Aurora-Mesh Gradient Hintergrund
- 📱 Vollständig responsive für alle Geräte
- 🎬 Video-Integration im Hero- und Portfolio-Bereich
- 🌐 Mehrsprachig (Deutsch & Englisch)
- ⚡ Optimierte Performance mit CSS Animations

## Struktur

```
Website Für Valu/
├── index.html           # Deutsche Startseite
├── en/index.html        # Englische Startseite
├── premium.css          # Haupt-Stylesheet
├── premium.js           # JavaScript-Funktionalität
├── Bilder/              # Bilder und Videos
├── datenschutz.html     # Datenschutzerklärung
├── impressum.html       # Impressum
├── robots.txt           # SEO Konfiguration
└── sitemap.xml          # Sitemap für Suchmaschinen
```

## Verwendete Technologien

- HTML5
- CSS3 (mit Animations und Backdrop Filters)
- Vanilla JavaScript
- Google Fonts (Manrope, Sora)

## Lokale Entwicklung

1. Repository klonen
2. Eine lokale HTTP-Server starten (z.B. mit Python: `python -m http.server 8000`)
3. Browser öffnen: `http://localhost:8000/Website\ Für\ Valu/`
